## 1. 🔍 ПРОВЕРКА ЭЛЕМЕНТОВ УПРАВЛЕНИЯ

### 📁 A. Узлы (Node.js)

- [x] **Выделение узла** (Клик ЛКМ по шапке/телу)  
  *Ожидается:* Появляется светящаяся рамка вокруг узла, справа открывается панель свойств.
- [x] **Групповое выделение** (Shift + Клик ЛКМ)  
  *Ожидается:* Добавление узла в выделение для совместного перемещения.
- [x] **Погружение в узел** (Двойной клик ЛКМ по телу узла)  
  *Ожидается:* Камера перемещается к содержимому узла, внешние узлы скрываются, меняется путь в верху.
- [x] **Кнопка «Папка» (📁 N)** в шапке узла  
  *Ожидается:* Вход внутрь узла-контейнера аналогично двойному клику.
- [x] **Стрелка «Вверх» (↑)** в шапке узла  
  *Ожидается:* Включение X-Ray Up для просвечивания карточек предков вверх по цепочке.
- [x] **Стрелка «Вниз» (↓)** в шапке узла  
  *Ожидается:* Включение X-Ray Down для просвечивания вложенных потомков без смены папки.
- [x] **Предпросмотр (Alt + Наведение)**  
  *Ожидается:* Начинка узла показывается поверх холста в полный размер, остальные объекты затухают.
- [x] **Изменение размера** (Потягивание за нижний правый угол)  
  *Ожидается:* Узел меняет ширину и высоту, ширина фиксируется.

## 2. 🚨 ЧЕК-ЛИСТ ВЫЯВЛЕННЫХ КОНФЛИКТОВ (ВСЕ ИСПРАВЛЕНЫ ✅)

- [x] **Конфликт 1: Глобальный X-Ray перекрывает локальный сброс на узле**  
  *Статус:* **ИСПРАВЛЕНО.** В `HierarchyUtils.getVisibilityState` доминирующее поузельное правило (seq > 0) получило приоритет над глобальным xRayDown.

- [x] **Конфликт 2: Сброс X-Ray на панели инструментов выбрасывает на Главный холст**  
  *Статус:* **ИСПРАВЛЕНО.** Из экшена `SET_XRAY_LEVEL` удален авто-сброс `currentContext` в `root`. Пользователь остается в текущем контексте.

- [x] **Конфликт 3: Исчезновение рамки Слоя при погружении в него**  
  *Статус:* **ИСПРАВЛЕНО.** В `Canvas.js` разрешен рендер слоя, если `layer.id === state.currentContext`. Слой подсвечивается как фоновый контейнер.

- [x] **Конфликт 4: Неожиданные прыжки контекста при одинарном клике в Дереве проекта**  
  *Статус:* **ИСПРАВЛЕНО.** Функция `handleSelect` в `Library.js` теперь производит выделение и центрирование камеры без вызова `GO_TO_CONTEXT`. Погружение внутрь происходит по двойному клику.

- [x] **Конфликт 5: Зависание зума при скролле текстовых списков**  
  *Статус:* **ИСПРАВЛЕНО.** В `Canvas.js` зум холста блокируется только в процессе прокрутки содержимого. При достижении верхней или нижней границы скролл естественным образом переходит в зум холста.
