📋 Тотальный аудит механик навигации, погружения и X-Ray

Проведен тотальный аудит механик навигации, погружения (Dive-In), выделения (Selection) и X-Ray просвечивания в приложении Architector.

1. 🔍 Покликный аудит элементов управления (Инвентаризация событий)

📁 A. Узлы (Node.js)

Элемент / Жест Событие Вызываемый Action / Функция Изменение состояния Визуальный результат
Заголовок / Тело узла MouseDown (ЛКМ) SET_SELECTED selectedIds = [node.id] Появляется светящаяся рамка вокруг узла (цвет data.color), панель свойств открывается справа.
Заголовок / Тело узла Shift + MouseDown (ЛКМ) TOGGLE_SELECTED Добавление/удаление node.id из selectedIds Массовое выделение узлов.
Тело узла DoubleClick (ЛКМ) DIVE_INTO currentContext = node.id, сброс selectedIds Камера плавно фокусируется на содержимом узла, внешние объекты скрываются.
Кнопка «Папка» (📁 N) Click (ЛКМ) DIVE_INTO currentContext = node.id Вход внутрь узла-контейнера.
Стрелочка ↑ (X-Ray Up) Click (ЛКМ) SET_NODE_XRAY_UP увеличение xRayNodes.up Просвечиваются предки узла вверх по иерархии (появляются полупрозрачные карточки).
Стрелочка ↓ (X-Ray Down) Click (ЛКМ) SET_NODE_XRAY_DOWN увеличение xRayNodes.down Просвечиваются вложенные потомки узла без смены текущего контекста.
Alt + Наведение MouseMove SET_UI ({ peekNodeId }) peekNodeId = data.id Peek-режим: Начинка узла просвечивается поверх холста в full-size, остальные затухают.
Отпускание Alt / Увод мыши KeyUp / MouseLeave SET_UI ({ peekNodeId: null }) peekNodeId = null Возврат к обычному виду.
Уголок изменения размера MouseDown (ЛКМ) UPDATE_NODE -> COMMIT_HISTORY node.size = {w, h} Узел меняет габариты, отключение авто-размера для ширины.

🎨 B. Слои (Layer.js)

Элемент / Жест Событие Вызываемый Action / Функция Изменение состояния Визуальный результат
Шапка слоя MouseDown (ЛКМ) SET_SELECTED + MOVE_SELECTED selectedIds = [layer.id], layers.position Слой выделяется и перетаскивается. Если слой заблокирован, его ноды едут вместе с ним.
Тело слоя Click (ЛКМ) SET_SELECTED selectedIds = [layer.id] Слой выделяется на холсте.

Кнопка Замка в шапке Click (ЛКМ) UPDATE_LAYER layers.locked = !locked Фиксация географических узлов при перемещении слоя.

Элемент Событие Вызываемый Action Изменение состояния Визуальный результат
Кнопка «Назад по истории» (←) Click (или Ctrl+[) NAV_BACK currentContext = pastEntry.id Камера возвращается к предыдущему посещенному контексту.

2. 🚨 ВЫЯВЛЕННЫЕ КОНФЛИКТЫ И СТРАННОСТИ В ЛОГИКЕ

🔴 Конфликт №1: Глобальный X-Ray перекрывает и блокирует поузельный сброс X-Ray
Локация: app/utils/hierarchy.js (getVisibilityState, строки 561-601)

Суть проблемы: В алгоритме видимости проверка Глобального X-Ray (блок 7a) исполняется РАНО, чем поузельный X-Ray (блок 7b). Если включить глобальный X-Ray (L1), а затем нажать стрелочку ↓ на конкретном узле для его скрытия, узел не скроется, так как глобальное правило перехватывает видимость первее.

🔴 Конфликт №2: Сброс X-Ray на Toolbar принудительно выбивает пользователя на Главный холст
Локация: app/store/reducer.js (SET_XRAY_LEVEL, строки 995-1018)

Суть проблемы: В редюсере зашит жесткий сброс контекста при val === 0. Если нажать кнопку L1 на Toolbar во вложенной папке для выключения просвечивания, вас мгновенно выбьет из папки назад на Главный холст (root).

🔴 Конфликт №3: Пропадание рамки Слоя при погружении в него через Хлебные крошки или Outliner
Локация: app/components/Canvas.js (строка 444) и app/utils/hierarchy.js

Суть проблемы: При currentContext === layerId проверка в Canvas layerParentContext !== state.currentContext возвращает true. Когда вы погружаетесь в Слой, сам фрейм слоя перестает рендериться, а его ноды остаются висеть в пустом пространстве без заглавной рамки.

🟡 Конфликт №4: Рассинхрон одинарного и двойного клика в OutlinerTree
Локация: app/components/OutlinerTree.js (строки 28-36) и app/components/Library.js

Суть проблемы: Одинарный клик вызывает handleSelect, который переключает контекст на родителя объекта, а двойной клик вызывает DIVE_INTO внутрь объекта. Попытка просто выделить объект в дереве одинарным кликом сопряжена с неожиданным переключением текущей папки.

🟡 Конфликт №5: Блокировка зума холста при скролле внутри AI-чата и текстовых полей
Локация: app/components/Canvas.js (обработчик wheel, строки 149-156)

Суть проблемы: Проверка scrollable.scrollHeight > scrollable.clientHeight блокирует событие зума холста, даже когда внутренний скролл докручен до самого конца.

3. 🎯 РЕКОМЕНДАЦИИ ПО ИСПРАВЛЕНИЮ И ОПТИМИЗАЦИИ

  • Приоритет X-Ray: В HierarchyUtils.getVisibilityState дать локальному конфигу узла xRayNodes[nodeId].down === 0 приоритет над глобальным xRayDown.
  • Сохранение контекста при выключении X-Ray: Убрать авто-выталкивание в root из редюсера SET_XRAY_LEVEL.
  • Видимость слоя-контейнера: Разрешить рендер рамки слоя при layer.id === state.currentContext.
  • Оптимизация OutlinerTree: На одинарный клик в дереве навесить исключительно SET_SELECTED + CENTER_ON_ENTITY без вызова GO_TO_CONTEXT.
