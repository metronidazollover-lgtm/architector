## П1. Стабильная геометрия шапки узла (стрелки без сдвига бейджа)

**Статус:** `[принято]`

**Проблема:** при наведении на бейдж 📁 стрелки X-Ray анимируются из `w-0` в `w-5`, бейдж сдвигается влево на ~20px — цель уезжает из-под курсора, промахи ведут либо к случайному dive, либо к случайному изменению X-Ray.

**Решение:** стрелки ↑/↓ всегда занимают своё место в шапке (резерв через `opacity`/`visibility`, а не ширину). В покое — бледные (`opacity ~0.35`), при hover шапки — полная яркость. Ничего не двигается.

**Файлы:** `app/components/Node.js` (блок бейджа, ~строки 487–566).

## П2. Развести навигацию (dive) и настройку вида (X-Ray)

**Статус:** `[принято]`

**Проблема:** одиночный клик по бейджу = смена контекста (dive), а соседние стрелки = настройка вида. Две механики с разной ценой ошибки сидят на соседних пикселях. Одиночный клик-навигация также нарушает конвенцию «одиночный клик = выделение».

**Решение (вариант по умолчанию — А):**
- **А.** Бейдж 📁 = только dive. Контролы X-Ray (− / глубина / +) переносятся в Quick Action Strip (мини-панель, уже открывающуюся по одиночному клику на узле).
- **Б.** (альтернатива) Стрелки остаются в шапке (по П1 — на фиксированных местах), но клик по бейджу на невыделенном узле сначала выделяет узел, и только клик по уже выделенному — dive.
- **В.** (альтернатива) Оставить как есть + добавить модификатор: Alt+клик по бейджу = X-Ray toggle, колесо мыши над бейджем = глубина X-Ray.

**Выбранный вариант:** `А`

**Файлы:** `app/components/Node.js`.

## П3. Двойной клик по всему узлу = Dive In

**Статус:** `[принято]`

**Проблема:** двойной клик как способ входа фактически не работает: заголовок по первому клику уходит в переименование и глушит dblclick, тело узла — в редактирование описания. Рабочая зона — узкие паддинги шапки.

**Решение:**
- Двойной клик по любой части узла (заголовок, тело, шапка) = `DIVE_INTO`.
- Переименование — по **F2** на выделенном узле и/или по одиночному клику на заголовке **уже выделенного** узла (паттерн Проводника/Finder).
- Редактирование описания — по одиночному клику в тело **уже выделенного** узла (аналогично).

**Файлы:** `app/components/Node.js` (обработчики заголовка ~457–465, тела ~847–854, hotkey F2 — `app/components/Canvas.js`).

## П4. Автогашение пер-узлового X-Ray при dive в этот узел

**Статус:** `[принято]`

**Проблема:** `xRayNodes[id]` переживает погружение: после входа в узел его конфиг продолжает «доминировать» по `seq` и менять поведение стрелок у детей, хотя внутри папки настройка избыточна (дети и так видны).

**Решение:** в редьюсере `DIVE_INTO` удалять (или обнулять) запись `xRayNodes[целевой id]`. Опционально: при выходе наверх (`NAVIGATE_TO`/Esc) — не восстанавливать.

**Файлы:** `app/store/reducer.js` (case `DIVE_INTO`, ~634–721), тесты `app/tests/reducer.test.js`.

## П5. Один источник правды для X-Ray

**Статус:** `[принято]`

**Проблема:** три источника состояния — глобальные `xRayDown/Up`, пер-узловые `xRayNodes`, seq-доминирование между ними. Клик по ↓ имеет 4 ветки поведения в зависимости от скрытого `isOwn`/`seq` — непредсказуемо для пользователя.

**Решение:**
- Пер-узловое значение — явный **override** поверх глобального (без seq-гонок): есть override — действует он, нет — глобальный.
- Клик по стрелке всегда делает одно и то же: инкремент глубины с циклом `0..max`.
- На узле с активным собственным override — постоянный видимый индикатор глубины (например, «👁 2» рядом с бейджем).
- Кнопка «Сбросить весь X-Ray» (тулбар или Обозреватель) очищает все override и глобальные уровни.

**Файлы:** `app/utils/hierarchy.js` (`getEffectiveNodeXRay`), `app/components/Node.js`, `app/components/Toolbar.js`, `app/store/reducer.js`, тесты `app/tests/hierarchy.test.js`.

## П6. Визуальный контейнмент просвеченных детей

**Статус:** `[принято]`

**Проблема:** дети, показанные через X-Ray, рендерятся по мировым координатам вне тела родителя — выглядят как посторонние узлы, могут налегать на соседей; связь «чей это ребёнок» не читается.

**Решение:**
- Полупрозрачный ореол/рамка родителя, охватывающая bounding box его просвеченных детей (расширенный контур с закруглением, цвет = `node.color` с низкой альфой).
- И/или пунктирная направляющая от родителя к каждому просвеченному ребёнку.

**Выбранный вариант:** `ореол + без пунктира`

**Файлы:** `app/components/Canvas.js` или `app/components/Node.js` (отрисовка ореола), `app/utils/hierarchy.js` (расчёт bbox).
