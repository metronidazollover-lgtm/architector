## 📌 1. Резюме и ответы на вопросы

1. **Возможна ли вложенность «Слой внутри Слоя»?**  
   **Да.** Модель данных приложения поддерживает произвольную вложенность координатных контейнеров через поле `parentId`. Слой может выступать родителем как для узлов (`nodes`), так и для других слоёв (`layers`).
   
2. **Отображается ли это в обозревателе проекта?**  
   * **Вкладка «Дерево» (`OutlinerTree.js`):** **Да, отображается.** Дерево рекурсивно запрашивает `childrenOf(layer.id)`, отображает счетчик дочерних элементов, стрелку сворачивания/разворачивания и визуальный отступ глубины (`depth * 14px`). Поддерживается перевложение через Drag & Drop строк.
   * **Вкладка «Слои» (`Library.js`):** **Нет.** В этой вкладке выводится плоский массив всех слоёв без учета их иерархической вложенности.

3. **Как взаимодействуют независимые слои на холсте?**  
   * Независимые слои (`parentId: 'root'` или разные родители) **не могут наехать друг на друга**. 
   * При перемещении срабатывает алгоритм выталкивания `GeometryUtils.resolveLayerCollision`, который автоматически отталкивает перемещаемый слой по кратчайшей оси с безопасным зазором `gap = 10px`.

## 🔬 2. Анатомия эффекта «галлюцинации» при создании слоев подряд

### Сценарий возникновения:
1. Пользователь создает 1-й слой нажатием кнопки «Добавить слой» на тулбаре.
   * Слой создается с `parentId: 'root'`.
   * Экшен `ADD_LAYER` в редьюсере автоматически делает его выделенным: `selectedIds: ['layer-1']`.
2. Пользователь нажимает «Добавить слой» второй раз.
   * Тулбар вызывает `HierarchyUtils.getAddContext(state)`.
   * Алгоритм видит, что выделен `layer-1`, и по правилу вложенности возвращает:
     ```javascript
     // Если выделен один слой — новый элемент создается ВНУТРИ этого слоя:
     return {
         ok: true,
         parentId: layer.id, // 'layer-1'
         levelIndex: HierarchyUtils.getEntityLevel(layer.id, nodes, layers)
     };
     ```
   * В итоге 2-й слой создается с `parentId: 'layer-1'` (дочерний контейнер), а `selectedIds` переключается на `['layer-2']`.
3. Третий слой аналогично становится дочерним для 2-го (`parentId: 'layer-2'`).

### Поведение при перемещении мыши:
* **Перемещение последнего добавленного слоя (Layer 3):**  
  Он является листом дерева (детей нет). Изменяются только его координаты относительно Layer 2. Визуально на холсте он перемещается один.
* **Перемещение первого добавленного слоя (Layer 1):**  
  Он является корнем дерева контейнеров. Расчет глобальных/локальных координат (`HierarchyUtils.getLocalPosition`) суммирует смещения всех предков. При движении родителя Layer 1 все дочерние слои (Layer 2, Layer 3) перемещаются вместе с ним как единое целое.

## ⚙️ 3. Коллизии независимых слоёв (`resolveLayerCollision`)

Когда слои находятся в одном контексте (`parentId === 'root'`), их перемещение подчиняется физике отталкивания:

```javascript
// Layer.js (handleMouseMove)
const resolved = window.GeometryUtils.resolveLayerCollision(
    data.id, rawX, rawY, lw, lh, state.layers
);
```

### Логика работы:
1. Находятся все соседние слои (`siblings`), имеющие тот же `parentId`.
2. Проверяется пересечение габаритов по обеим осям с учетом зазора:
   ```javascript
   const overlapX = x < ox + ow + gap && x + movingW + gap > ox;
   const overlapY = y < oy + oh + gap && y + movingH + gap > oy;
   ```
3. При пересечении вычисляются расстояния выталкивания в 4 стороны (`pushRight`, `pushLeft`, `pushDown`, `pushUp`).
4. Слой выталкивается по вектору минимального сопротивления (`minPush`).
5. Цикл повторяется до 5 итераций для корректной обработки каскадных соударений.

## 📋 4. Сводная таблица взаимодействия сущностей слоев

| Ситуация | Поведение на холсте | Поведение в «Дереве» | Поведение во вкладке «Слои» |
| :--- | :--- | :--- | :--- |
| **Слой создан при пустом выделении** | Независимый слой (`parentId: 'root'`) | Корень уровня (L0/L1) | Строка в списке |
| **Слой создан при выделенном слое** | Вложенный слой (координаты относительны родителя) | Дочерний узел внутри родительского слоя | Строка в списке (без отступа) |
| **Перемещение родительского слоя** | Двигает сам слой и все вложенные в него слои/узлы | Без изменений | Без изменений |
| **Перемещение вложенного слоя** | Двигает только себя внутри рамки родителя | Без изменений | Без изменений |
| **Сближение двух независимых слоев** | Выталкивание (`resolveLayerCollision`, gap 10px) | Без изменений | Без изменений |

## 💡 5. Выводы и утвержденный план решений

1. **Позиционирование независимых слоёв:** Добавление слоя на холст создаёт слой ниже существующих с зазором `gap = 10px` (`parentId: 'root'`).
2. **Кнопка «Назначить на слой» в панели свойств слоя:** Добавляется в ContextActionBar с автоподгонкой размера родителя.
3. **Режим Drag & Drop для слоёв:** Перемещение в другой слой с запросом подтверждения; при отмене — возврат на исходное место.
4. **Контекстная кнопка «+» (FAB):** При выделении слоя кнопка и веер переключаются на режим наполнения слоя (добавить узел / ассистента / вложенный слой внутрь).
