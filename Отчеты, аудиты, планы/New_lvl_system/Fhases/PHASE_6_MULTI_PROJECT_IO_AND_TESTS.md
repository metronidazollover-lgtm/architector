## 📋 Подробный состав задач Фазы 6

### 6.1. Двухуровневая система Импорта / Экспорта
1. **Глобальный экспорт / импорт (Workspace Level):**
   - Экспорт: сохранение всех проектов (`state.projects`), окон уровней (`levelWindows`), камер и межпроектных связей в единый `.arch-space` файл.
   - Импорт: полная загрузка мульти-проектного пространства на мировой холст.
2. **Локальный экспорт / импорт (Project Level):**
   - Экспорт: выгрузка выбранного проекта (`state.projects[pid]`) со всеми внутренними уровнями.
   - Импорт (диалог выбора пользователя):
     - Вариант А: *«Добавить как новый проект на холст»* (генерация нового `projectId`).
     - Вариант Б: *«Слияние / вставка внутрь активного проекта»* (перегенерация ID нод во избежание коллизий).

### 6.2. Кросс-проектные связи и переносы
- Сквозная маршрутизация линий связей между портами разных проектов на общем холсте.
- Перенос узла или ветки из Проекта A в Проект B через экшен `REPARENT_ENTITY` с параметром `targetProjectId`.

### 6.3. Комплексное тестирование и валидация
1. **Автоматизированные юнит-тесты:**
   - Запуск полного сьюта тестов:
     ```bash
     node --test app/tests/*.test.js
     ```
   - Должны успешно проходить: `migration.test.js`, `reducer.test.js`, `hierarchy.test.js`, `coords.test.js`, `geometry.test.js`, `reactivity.test.js`, `engine.test.js`.
2. **Бенчмарки производительности:**
   - Запуск `app/bench/core.bench.js` (чистая логика).
   - Проверка отсутствия лагов и утечек памяти при массовом перетаскивании.
3. **Ручная сквозная проверка сценариев (E2E):**
   - Создание многоуровневого проекта $\rightarrow$ перенос веток $\rightarrow$ вырывание через Shallow $\rightarrow$ сохранение $\rightarrow$ экспорт $\rightarrow$ импорт в чистый браузер.
