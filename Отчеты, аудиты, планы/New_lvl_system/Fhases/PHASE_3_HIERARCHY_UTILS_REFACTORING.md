## 📋 Подробный состав задач Фазы 3

### 3.1. Реализация правила семантического шага в `getEntityLevel`
- Алгоритм: вычисление глубины цепочки `parentId` до корня (`'root'`).
- **Критическое правило (из премортема):** Инкремент уровня происходит **только при прохождении через Узел (`nodes[id]`)**. Прохождение через Слои (`layers[id]`) координатную вложенность меняет, но уровень оставляет неизменным.
- Мемоизация через `WeakMap` для мгновенного доступа O(1).

### 3.2. Универсальная быстрая защита от циклов (`isDescendantOf`)
- Проверка перед любым изменением `parentId`:
  ```js
  isDescendantOf: (targetId, draggedId, nodes, layers) => {
      // Возвращает true, если targetId лежит внутри draggedId
  }
  ```
- Исключает циклы вложения как для узлов, так и для вложенных слоев.

### 3.3. Обновление детектора целей сброса (`getDropTarget`)
- **При DnD = ВЫКЛ:**
  - Цели за пределами текущего окна уровня отклоняются (`valid: false, reason: 'dnd-off'`).
  - Разрешена только расстановка внутри окна своего уровня и базовое вложение в слой своего уровня.
- **При DnD = ВКЛ:**
  - Разрешены кросс-уровневые сбросы (на узел другого уровня $\rightarrow$ вложение, в слой другого уровня $\rightarrow$ группировка, на холст окна $\rightarrow$ смена уровня).
  - Приоритет целей при наложении: `Узел > Слой > Окно уровня`.

### 3.4. Удаление рудиментов и мертвого кода
- Полное удаление методов: `getOwnerGap`, `getBranchOwner`, `canTransferToLayer` (замена на одну универсальную проверку `!isDescendantOf`).

### 3.5. Покрытие юнит-тестами (`app/tests/hierarchy.test.js`, `app/tests/coords.test.js`)
- Тестирование вычисления уровней для сложных конструкций (Узел в Слое, Слой в Слое, Ветка на 5 уровней).
- Тестирование защиты от циклических зависимостей.
