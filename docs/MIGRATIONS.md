## v11 → v12: мультипроектная обёртка

**Что изменилось.** Состояние перестало быть плоским. Прежний корень (сущности, окна уровней, камеры, история) целиком переехал внутрь одного проекта, а над ним появился слой мультипроектности:

```
{
  formatVersion: 12,
  projects: { <projectId>: { id, origin, ...все поля проекта } },
  projectOrder: [<projectId>, ...],
  activeProjectId: <projectId>,
  projectCounter: <number>,
  canvas, ui, selectedIds, ...        // глобальные поля, общие для всех проектов
}
```

**Поля проекта** (`PROJECT_FIELDS`): `projectName`, `projectColor`, `projectFontFamily`, `projectContent`, `levelWindows`, `levelViews`, `activeLevelIndex`, `levelFocusParentId`, `levelHideNeighbors`, `layers`, `nodes`, `ports`, `links`, `past`, `future`, `historyLogs`.

Ключевое следствие: **история Undo у каждого проекта своя** — отмена в одном проекте не затрагивает соседний.

**Как выполняется миграция.** `wrapFlatToMulti(flat)` заворачивает любое плоское состояние (v9/v10/v11 после соответствующих миграций) в один проект. Обратной операции нет: `mergeActiveView(m)` строит плоский ВИД активного проекта для компонентов и внутреннего редьюсера, поэтому весь прежний код продолжает читать `state.nodes` без изменений.

**Ключ хранилища:** `architector_state_v12`. Легаси-ключи не удаляются.

**Уникальность id окон.** Окна разных проектов не должны иметь общих id: они служат React-ключами и адресуют окно в выделении. Первый (мигрированный) проект сохраняет зарезервированный `lvlwin-root`, новые проекты получают сгенерированные id.

### Что НЕ переживает перезагрузку страницы (с 2026-08-24)

Массивы `past` / `future` очищаются перед записью в `localStorage`. История Undo полностью работает в пределах вкладки, но после перезагрузки страницы начинается с чистого листа. Это сознательный размен: 20 снимков сущностей на проект гарантированно переполняли квоту браузера (~5 МБ) на сколько-нибудь крупном проекте, после чего приложение навсегда оставалось в аварийном режиме сохранения.

Также не персистится транзиентное поле `historyBatch` (маркер открытого пакета истории).

### Поля, добавленные после v12

Аддитивные, миграции не требуют — отсутствие означает значение по умолчанию:

* `aiChatSessionsByNode` — мультисессии чата узлов-ассистентов (восстанавливается при загрузке);
* `ui.aiAgentSettings.confirmMode` — `'ask'` (по умолчанию) или `'auto'`: спрашивать ли подтверждение перед применением команд ИИ;
* `containerIsolation: { projectIds, windowIds }` — изоляция контейнеров на общем холсте. Глобальное поле, в историю Undo не входит (как и камера). Автоматически очищается при удалении изолированного контейнера, иначе на холсте не осталось бы ни одного видимого контейнера, а вместе с ним и кнопки выхода из режима;
* `historyBatch` — транзиентный маркер пакета истории.
