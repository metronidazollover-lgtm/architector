# Карта жестов и хоткеев

Обновляется каждым этапом плана (docs/PLAN.md).

## Мышь

| Жест | Действие |
|---|---|
| Клик по узлу/слою | Выделить узел/слой (открыть верхнюю контекстную панель свойств под строкой навигации; визуально подсветить собственные порты, присоединенные связи, противоположные порты и соединенные ноды) |
| Клик по связи | Выделить связь (открыть верхнюю контекстную панель свойств) + визуально подсветить соединенные порты (белое кольцо, масштабирование x2.1) и соединенные ноды (обводка и тень) |
| Клик по порту | Выделить порт (открыть верхнюю контекстную панель свойств, масштабирование x2.1) + визуально подсветить присоединенные связи, противоположные порты и соединенные ноды |
| Клик по порту с межуровневой связью | Проявить соединенный узел с другого уровня и протянуть линию связи. Клик по проявленному узлу активирует его свойства в верхней панели, подтягивает соединенные элементы его уровня и позволяет свободно навигировать по цепочке связей (Chain Navigation) в обоих направлениях («сверху-вниз» и «снизу-вверх») |

| Shift+клик | Добавить/убрать из выделения |
| Перетаскивание узла | Переместить (потомки едут вместе, v10; встроенная панель действий остаётся скрытой) |
| Перетаскивание шапки слоя | Переместить слой (замок: захват соседей по контексту в границах; слои автоматически скользят по границам друг друга, не допуская перекрытий) |
| Уголок справа внизу | Изменить размер |
| Двойной клик по узлу | Открыть папку / войти внутрь (Dive In) |
| Клик по бейджу «📁 N» в шапке узла | Открыть папку / войти внутрь (Dive In) |
| Двойной клик по порту / связи | Выделить порт или связь и открыть свойства в панели действий |
| Alt+наведение на узел с детьми | Peek: начинка в полный размер, соседи приглушены; отпустить Alt — вернуть |
| Перетаскивание от порта | Векторно-направленная создаваемая связь (линия тянется строго к курсору мыши; умное создание порта при сбросе на узел) |
| Колесо | Зум в точку курсора |
| Средняя кнопка / Shift+ЛКМ по холсту | Панорама |
| Клик по пустому холсту | Сброс выделения |

## Интерактивная Адресная строка пути (Address Bar — Windows Explorer style)

Навигация графа полностью работает в знакомом стиле **Проводника Windows / VS Code**:
- **Кликабельный путь:** `🏠 Главный холст ❯ 📁 UI Layer ❯ 📦 Header Component`. Каждый сегмент — кликабельная кнопка для переключения контекста в 1 клик.
- **Быстрые кнопки навигации:** `[ ⬅ Назад ]` (`Ctrl+[`), `[ ➔ Вперед ]` (`Ctrl+]`), `[ ⬆ Наверх (Esc) ]`.
- **Визуальные Узлы-Папки:** ноды со вложенными объектами помечаются иконкой `📁` и бейджем `📁 N объектов`. Двойной клик по узлу или клик по бейджу мгновенно открывает папку.
- **Чистый холст (100% папка):** при открытии папки на холсте видны только её элементы (`getRelativeDepth === 1`). Размытые фона-призраки предков удалены.
- **Динамический X-Ray:** просвечивание регулируется в Обозревателе (`Library.js`) с динамическим расчетом максимального числа уровней графа `0..maxDown`.

На левой панели инструментов расположена кнопка **«Загрузить тестовый проект (Тест)»**. 
При её нажатии загружается наглядный тестовый граф со структурированным набором элементов:
- **3 основных слоя** (0. Руководство, 1. Контейнеры Узлов А и Б, 2. Специальные типы Узлов В, Г, Д).
- **Многоуровневая вложенность:** 1-й уровень (`Узлы А, Б, В, Г, Д`), 2-й уровень (`Узлы А1, А2, А3, Б1, Б2`), 3-й уровень (`Узлы Б1.1, Б1.2`).
- **Различные типы связей:** внутриуровневые связи между соседними узлами и межуровневые связи, пересекающие границы контейнеров.
- **Специальные виджеты:** медиа-карточка с картинкой (Узел В) и ИИ-копилот (`type: 'ai-agent'`, Узел Г).

## Верхняя контекстная панель свойств и типографика (Context Action Bar)

- **Центральное расположение:** Панель расположена вверху по центру экрана строго под строкой навигации (`top-16`, максимальная ширина `794px` — формат A4).
- **Мгновенное открытие:** Появляется при выделении любого элемента (Узел, Слой, Порт, Связь) или группы элементов (Массовое выделение).
- **3-ярусная компоновка:**
  - **1. Верхний ярус:** Бейдж типа сущности (`📦 Узел`, `🔲 Слой`, `🔌 Порт`, `⚡ Связь`, `👥 Выбрано: N`), поле ввода **Названия** с рендерингом в выбранной гарнитуре, кнопка **копирования системного ID** и кнопка сброса выделения (`✕`).
  - **2. Средний ярус (40×40px):** Полноразмерные кнопки функций стандартного размера `w-10 h-10` с выпадающими стеклянными поповерами:
    - **Типографика `[ 🔤 ]`:** выбор гарнитуры из 11 пресетов (Modern Sans, Monospace, Serif, Rounded, Condensed) и 7 размеров шрифта (`11px..24px`).
    - **Цвета `[ 🎨 ]`:** 14 контрастных палитр + HTML5 Color Picker для тонкой настройки.
    - **Иконки и эмодзи `[ 😊 ]`:** быстрый выбор из каталога Lucide Icons и эмодзи-пикера.
    - **Медиа `[ 🖼️ ]`:** прикрепление изображений по URL с интерактивным слайдером высоты.
    - **Привязка к сетке `[ ▦ ]`:** тогл выравнивания по сетке 30px.
    - **Слои `[ 🗂️ ]`:** быстрое перемещение узлов на слои с авто-раскладкой `getSmartPlacement`.
  - **3. Нижний ярус:** Сразу открытое компактное поле **Описания** (1 строка по умолчанию с динамическим ростом до 140px без ранних скроллбаров).

## Автоподстройка, перенос текста и ручной размер узлов

- **Автоподстройка под контент на лету (Live Auto-Sizing):** При наборе текста в полях «Имя» или «Описание» узел динамически и плавно увеличивает свои размеры (ширину и высоту) в реальном времени.
- **Многострочные заголовки и перенос строк (`break-all`):** При достижении максимальной горизонтальной границы A4 (794px) заголовок автоматически переносится на следующую строку, а шапка узла растёт вниз.
- **Умные скроллбары:** В стандартном режиме прокрутка скрыта, а кастомный скроллбар активируется только тогда, когда пользователь вручную сжал узел (`userResized: true`) меньше объема его текста.
- **Сохранение ручного размера:** Если вы вручную изменили размер узла с помощью уголка справа внизу, этот размер фиксируется (устанавливается флаг `userResized`). При косметических изменениях (переименование, изменение цвета фона) этот ручной размер **не сбрасывается** (автоподстройка работает только как нижняя граница безопасности, чтобы текст не вылезал). Однако при значительном изменении наполнения (ввод нового описания, смена/удаление картинки) ручной размер сбрасывается, и узел снова подстраивается под контент.

## Авторасстановка на слоях и оптимизация размеров

- **Автоматическая раскладка:** При перетаскивании, импорте проекта/ИИ-генерации (в экшене `LOAD_STATE`), или назначении узлов в слой через верхнюю контекстную панель свойств (как для одного узла, так и для нескольких), система автоматически вычисляет бесконфликтные координаты для нод, исключая их перекрытие.
- **Оптимизация (Fit-to-Content):** Слой автоматически подгоняет свои размеры (ширину и высоту) под занимаемую его элементами область плюс отступы (padding = 20px, верхний отступ под шапкой = 90px). Это работает как в сторону увеличения, так и в сторону уменьшения (слой аккуратно сжимается вокруг оставшихся в нём нод). Вы также можете запустить автовыравнивание в любой момент кнопкой «плитка» в шапке слоя.

## Предотвращение перекрытия слоёв (Коллизии)

- При ручном перетаскивании слоя за шапку, он взаимодействует с другими слоями на этом же уровне иерархии.
- Слои **не могут перекрывать друг друга**: если вы двигаете один слой на другой, перемещаемый слой начнет аккуратно скользить по границам соседнего слоя с зазором в 10px, выталкиваясь по кратчайшему пути.
- Это позволяет легко организовывать пространство и выстраивать слои стык-в-стык без хаотичного наложения.
- **Внешние отдельные ноды:** При автоматической генерации архитектур ИИ или загрузке проекта (`LOAD_STATE`) отдельные ноды, лежащие на одном уровне со слоями, автоматически расталкиваются от границ слоев на расстояние не менее **30px** и друг от друга на расстояние не менее **30px**. При ручном перетаскивании это ограничение не накладывается, чтобы пользователь мог свободно размещать элементы по своему желанию.
- **Предотвращение наложения слоев при импорте:** Перекрывающиеся слои автоматически расталкиваются с зазором **30px** при `LOAD_STATE`, чтобы ИИ-генерации не создавали наложенных друг на друга фреймов. Ваше собственное сохраненное ручное расположение (без перекрытий) сохраняется нетронутым.
- **Кнопка «Выровнять слои»:** При наличии 2 и более слоев в текущем контексте на левой панели тулбара появляется кнопка «Выровнять слои» (CAD-иконка вертикального выравнивания слоев). При нажатии слои выстраиваются по вертикали друг под другом с зазором **90px** по порядку номеров/имени (natural sort). Вы всегда можете отменить это выравнивание кнопками Undo/Redo или расположить слои вручную.

## Пульсация родительских узлов

- При выделении любого дочернего узла на любом уровне вложенности его родительский узел-контейнер начинает плавно и благородно пульсировать своим собственным цветом (`node.color`). 
- Пульсация происходит за счет анимации тени (`box-shadow`) и обводки (`outline`) с отступом 4px. Это помогает быстро понять, куда вложен выбранный элемент, не захламляя экран лишними рамками.

## Обозреватель проекта и Панель инструментов

- **Расположение панели Обозревателя:** Окно Обозревателя размещается у самого левого края экрана (`left-4 top-4`) с шириной **350px**. По умолчанию при старте чистый холст открывается с закрытым Обозревателем.
- **Динамический сдвиг Панели инструментов:** При открытии Обозревателя кнопкой на тулбаре Панель инструментов плавно сдвигается вправо на позицию `left-[382px]` (`transition-all duration-300`). При закрытии Обозревателя тулбар плавно возвращается в положение `left-4`.
- **3 Главные вкладки:** Шапка Обозревателя содержит 3 основных пункта: **«Объекты»**, **«Уровни»** и **«История»**.
  - **«Объекты»:** подвкладки *Дерево*, *Слои*, *Узлы*, *Порты*, *Связи*.
  - **«Уровни»:** иерархический список всех узлов-контейнеров с детальной статистикой вложенности (Уровень 0 — Главный холст, Уровень 1+) и прямым входом по двойному клику.
  - **«История»:** хронологический лог действий проекта с кнопками Undo/Redo.
- **Унифицированный клик закрытия:** Нажатие на кнопку «Обозреватель проекта» на Панели инструментов мгновенно сворачивает окно с одного клика независимо от активной вкладки.

## Навигация по уровням и X-Ray

- **Контекстная плашка навигации сверху:** Индикатор текущего контекста и кнопка `[ ⬆ Наверх (Esc) ]` для моментального перехода. При переходе в пустой контекст выводится сообщение `Пусто (Esc — наверх)`.
- **Контекстно-относительный X-Ray:** Просвечивание управляется относительно текущей позиции (`xRayDown` 0..3 уровней вглубь, `xRayUp` 0..2 уровней наверх) через вкладку «Навигация» в Обозревателе или быстрые контролы на Панели инструментов. Настройки X-Ray сохраняются при навигации по уровням.
- **Взаимодействие на X-Ray уровнях:** Вы можете полноценно выделять, перемещать и редактировать любые просвечиваемые элементы.
- **Перемещение контекстного узла:** Вы можете перетащить за шапку или тело активную ноду, внутри которой находитесь в данный момент — она сместится вместе со всеми внутренними детьми.
- **Сохранение камер:** Камера каждого уровня запоминается в `cameraByContext` и восстанавливается при возврате.
